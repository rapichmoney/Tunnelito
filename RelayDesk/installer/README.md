# Установщик Tunnelito

Запусти `Tunnelito-Setup-<версия>-x64.exe` и подтверди запрос Windows. Новая установка размещается в Program Files; при обновлении RelayDesk используется его прежняя папка. .NET и ядра sing-box, Xray, mihomo, Flowseal/zapret входят в пакет.

Данные остаются в `%LOCALAPPDATA%\RelayDesk`. Существующие внешние ядра и профили сохраняются. Основной EXE — Tunnelito.exe, совместимый вход для старых ярлыков — RelayDesk.exe. Оба используют одну сборку и один mutex. AppId прежний, второй продукт не создаётся.

Перед заменой файлов установщик запрашивает состояние работающего приложения по IPC. VPN, zapret и оверлей закрываются через обычный жизненный цикл; после установки восстанавливаются выбранные компоненты, сервер и черновики. Если приложение занято, установщик ждёт или сообщает об ошибке до замены файлов.

Удаление сохраняет пользовательские данные и убирает задачи автозапуска, указывающие на установленные EXE. Старые ярлыки установщика заменяются на Tunnelito. Пользовательский ярлык вне стандартных папок продолжит работать через совместимый EXE.

Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1 -Repository rapichmoney/Tunnelito`. Нужны .NET SDK 9 и Inno Setup 6. Версия берётся из `RelayDesk.csproj`, результат — в `output`.

Версии и SHA-256 ядер закреплены в `cores.lock.json`. Пользовательские профили, ключи и журналы в пакет не входят. Установщик пока не подписан сертификатом издателя.

Тестовый пакет использует отдельный AppId. `HandoffTestBuild` позволяет проверить обновление изолированной копии без повышения прав и без изменения рабочей программы. `RelayDesk.Checks/UpdateCycle.ps1` проверяет закрытие старого EXE, замену файлов и восстановление ядра; каталог и PID задаются явно.
