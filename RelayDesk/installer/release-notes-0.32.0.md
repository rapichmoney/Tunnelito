# Tunnelito 0.32.0

RelayDesk теперь называется Tunnelito («Туннелито»). Репозиторий переименован с сохранением истории и прежних релизов: https://github.com/rapichmoney/Tunnelito.

- Новое имя и знак маршрута в Orbit, классическом интерфейсе, трее, уведомлениях и установщике.
- При первом запуске после обновления RelayDesk переходит в Tunnelito за 850 мс. Повторный запуск — появление за 220 мс. При уменьшении движения название показывается сразу.
- При переключении подключения знак один раз прорисовывает маршрут. Цвет запущенного подключения появляется после завершения запуска ядра; доступ в интернет проверяется отдельно через HTTPS.
- Основной запуск — Tunnelito.exe. RelayDesk.exe оставлен для прежних ярлыков и задач Windows. Идентификатор установки и папка данных остаются прежними.
- Обновлятор использует rapichmoney/Tunnelito и принимает проверенные пакеты с прежних адресов проекта. Проверка SHA-256 сохранена.

Профили, подписки, правила, выбранный сервер и настройки сохраняются. Установщик перед заменой файлов запрашивает состояние работающей программы, закрывает её и восстанавливает VPN/zapret после установки. Несохранённые поля возвращаются как черновики. Логика ядер и маршрутизации не менялась.

Для перехода с RelayDesk 0.31.0 и более ранних версий скачай установщик вручную: их обновлятор не принимает адреса после переименования GitHub-аккаунта. В Tunnelito дальнейшие обновления используют новый адрес.
