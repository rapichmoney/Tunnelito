# Tunnelito 0.33.0

- Под названием Tunnelito появилась зелёная полоса подключения. Она заполняется до конца только после запуска ядра; название плавно набирает зелёный цвет. При отключении полоса и насыщение убираются. Уменьшение движения учитывается.
- Подпись «VPN и zapret» удалена из верхней панели Orbit и классического интерфейса.
- На Земле выделяется контур страны выбранного VPN-сервера. Используются встроенные границы Natural Earth; геометрия кэшируется и вращается вместе с планетой.
- В режиме zapret показывается точка исходного подключения. Положение определяется запросом к ipwho.is через обычный IPv4-интерфейс без системного прокси. На запрос не переключаются маршруты и не отключается VPN.
- Положение кэшируется на час для текущего интерфейса. Нажатие на карточку zapret или «Обновить положение» повторяет запрос. Если прямой запрос не прошёл, приложение сообщает об этом и не использует положение VPN вместо исходного.
- На основных подписях карты убраны «примерно» и «приблизительно». Для VPN отображается страна, для исходной точки — данные города и страны провайдера.

Исходный IP в настройках не сохраняется. Геолокация IP не определяет точный адрес устройства. Профили, правила маршрутизации, параметры TUN и логика ядер не изменены.
