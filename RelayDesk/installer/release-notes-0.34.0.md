# Tunnelito 0.34.0

- Планету можно вращать зажатой левой кнопкой мыши. Ручной вид не сбрасывается при обновлении состояния подключения.
- Колесо мыши приближает и отдаляет планету в пределах 1–4×.
- Двойной щелчок возвращает камеру к выбранной локации и переключает приближение 1× / 2,4×.
- Новая локация снова автоматически поворачивает планету. Уменьшение движения учитывается.
- Жесты работают только на планете главного экрана и не перехватывают нажатия кнопок интерфейса.

Профили, настройки и маршруты не изменены.
