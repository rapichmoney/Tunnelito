# Tunnelito 0.35.0

- В разделе «Приложения и правила» можно вставить список до 20 000 доменов. Есть предпросмотр, выбор маршрута, проверка повторов и пересечений с существующими правилами.
- Доменные правила экспортируются в JSON и TXT. Оба формата можно импортировать обратно с сохранением типов, маршрутов и порядка.
- Большие списки правил показываются по 100 строк на странице.
- В настройках появилась переустановка четырёх ядер Tunnelito. Сначала загружаются закреплённые версии из установщика и проверяются SHA-256 и конфигурации, затем восстанавливается прежнее подключение. Старые управляемые загрузки ядер удаляются после успешной замены. Другие VPN-программы не затрагиваются.
- Orbit с планетой становится интерфейсом по умолчанию при обновлении. После этого выбранный вручную классический интерфейс сохраняется.

Профили, подписки и правила пользователя сохраняются.
