# Tunnelito 0.35.3

- Для sing-box включён поиск процессов в конфигурации запуска, даже если ещё нет правил приложений. Это исправляет отсутствие названий приложений в соединениях на свежей установке с TUN.
- Настройка применяется и при уже заданном Clash API. Адрес API, пароль и правила маршрутов сохраняются.

После обновления переподключи VPN. Настройка действует для новых соединений; отдельные системные или уже закрывшиеся процессы могут оставаться неопределёнными.
