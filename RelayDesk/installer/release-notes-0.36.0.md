# Tunnelito 0.36.0

- В настройках появилась функция HTTPS-перехвата для sing-box. Она выключена по умолчанию.
- Если зависимый GET/HEAD-запрос получил 403, а Referer/Origin указывает на сайт с правилом VPN, Tunnelito повторяет запрос через VPN один раз. После ответа 2xx точный домен временно используется через VPN для связанных запросов на 30 минут. Неуспешный повтор не добавляет правило.
- Явные доменные исключения «напрямую» сохраняют приоритет. POST и другие изменяющие запросы не повторяются. Временные правила можно очистить в настройках.
- Установщик добавляет отдельный сертификат Tunnelito для текущего пользователя Windows. Windows может запросить подтверждение доверия. Закрытый ключ хранится с защитой DPAPI, сертификат не общий для установок. Доверие удаляется в настройках и при удалении приложения.
- Добавлены доменные исключения из расшифровки и журнал с доменами и кодами ответа, без URL-путей, cookies и тел запросов.

Перехват использует системный HTTP-прокси и действует для приложений, которые его соблюдают, в том числе при TUN. Браузеры с отдельным прокси/VPN и приложения с закреплёнными сертификатами могут не поддерживаться. Если браузер не передаёт Referer/Origin, связь с исходным сайтом не угадывается. Это не полная цепочка JavaScript-инициаторов из DevTools. Обновление с отключённой функцией не включает перехват.
