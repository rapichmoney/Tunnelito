# Tunnelito 0.36.1

- HTTPS-проверка распознаёт неполные и зависшие ответы 200 для GET-файлов до 4 МиБ включая сжатые ответы и передачу chunked.
- Связанный с VPN-сайтом запрос повторяется через VPN один раз. Браузер получает полный файл; временное правило создаётся только после успешной полной загрузки.
- При неудачном повторе возвращается 502. POST, Range, потоки, большие файлы и явно назначенные прямые домены не переключаются этой проверкой.
- В журнале различаются сетевые ошибки, TLS и отмена запроса. Содержимое запросов, cookies и полные URL в журнал не попадают.
- Профили, подписки, маршруты и выбранные режимы сохраняются.
