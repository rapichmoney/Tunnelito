# Tunnelito 0.36.3

- Исправлен смешанный маршрут приложений: если sing-box не определил владельца UDP, Tunnelito использует резервное правило по локальному порту Windows.
- Проверка владельцев выполняется каждые две секунды. Правила обновляются без перезапуска VPN, только для UDP из TUN с неизвестным процессом.
- Общие порты, порты с неизвестным владельцем и служебные multicast-порты не назначаются приложению.
- Существующие соединения сохраняют маршрут до переподключения. После обновления приостанови и возобнови загрузку в торрент-клиенте.
- Исходные конфигурации, профили, подписки и настройки сохраняются.
