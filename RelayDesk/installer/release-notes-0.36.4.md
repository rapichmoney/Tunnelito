# Tunnelito 0.36.4

- Добавлена поддержка happ://crypt4/ при вставке из буфера, сканировании QR и добавлении подписки.
- Расшифровка выполняется локально; сервисы расшифровки не используются. В сохранённой подписке остаётся зашифрованная ссылка.
- Перед добавлением открывается обычный выбор серверов. Работающее подключение не меняется.
- Повреждённые ссылки и неподдерживаемые версии шифрования показывают отдельное сообщение. Полные ссылки Happ скрываются в журнале.
- Провайдер может ограничивать допустимые приложения. Поддержка crypt4 не отменяет его ограничения; crypt5 пока не поддерживается.
