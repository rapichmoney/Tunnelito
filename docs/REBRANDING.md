# Переход RelayDesk → Tunnelito

Tunnelito («Туннелито») — новое имя приложения: tunnel + utility. Переименован существующий репозиторий, его история, Issues и релизы сохранены. Новый владелец после смены имени аккаунта — rapichmoney.

Поиск GitHub `Tunnelito in:name` перед переименованием 18 ноября 2026 года вернул 0 репозиториев. Это результат поиска, а не регистрация товарного знака.

## Идентификаторы и данные

| Объект | После обновления |
| --- | --- |
| Название, основной EXE и ярлыки | Tunnelito, Tunnelito.exe |
| Совместимый EXE | RelayDesk.exe; тот же apphost, сборка и mutex |
| Сборка, пространства имён | RelayDesk.dll, RelayDesk |
| Папка данных | `%LOCALAPPDATA%\RelayDesk` |
| AppId установки | `RelayDesk-Desktop-A7B02E29-4D16-47F0-B8F3-3B829E1F024D` |
| Задача автозапуска | `RelayDesk.Startup.<SID>`; обновляется путь запуска |
| Mutex и IPC | Прежние `RelayDesk.*` |
| QR и переменная тестовых данных | `relaydesk-share-v1`, `relaydesk-qr-v1`, `RELAYDESK_DATA_DIR` |

Переезд папки данных не требуется. Установщик с прежним AppId обновляет существующую установку, а не создаёт второй продукт. Старые пользовательские ярлыки продолжают работать через RelayDesk.exe. Стандартные ярлыки установщика заменяются на Tunnelito.

При первом запуске добавляется только `BrandingVersion=1` в настройки. Если настройки существовали до обновления, показывается переход названия за 850 мс. На чистой установке сразу используется Tunnelito. Повторное появление — 220 мс; при уменьшении движения анимации нет.

## Обновлятор

Основной источник — `rapichmoney/Tunnelito`. Разрешены также прежние адреса того же проекта: `rapichmoney/RelayDesk-VPN` и `bernicetownsend1955/RelayDesk-VPN`. Пакеты принимаются только с GitHub из этих адресов, с точной версией и именем Tunnelito-Setup или RelayDesk-Setup. Размер и SHA-256 проверяются при скачивании и перед установкой. Другие репозитории и серверы не разрешены.

Старый клиент RelayDesk 0.31.0 проверяет адрес пакета по старому имени владельца и репозитория. GitHub перенаправляет старый URL, но в ответе API возвращает новое имя. Изменить уже установленный код через переадресацию невозможно: первый переход выполняется вручную. После установки Tunnelito дальнейшие обновления используют новый адрес.

## Проверки

Ребрендинг проверяется на тестовых данных: Orbit, классический интерфейс, первый и повторный запуск, выключенные анимации, окончание прорисовки знака, сохранение JSON и выбранного профиля. Существующие проверки ядра, маршрутов, импорта, QR и интерфейса выполняются отдельно. Обновление тестовой установки проверяет остановку собственного ядра, замену файлов и восстановление подключения.

Скриншоты и GIF используют тестовую подписку. Личные данные, журналы, ключи и резервные копии не включаются в исходники и установщик. Анимация знака подтверждает состояние ядра; сеть проверяется отдельно через HTTPS. Логика sing-box, Xray, mihomo и zapret в ребрендинге не изменяется.
